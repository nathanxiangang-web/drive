# CloudDrive 备份与恢复

备份服务随 Compose 启动，每天北京时间 03:00 将 `my-serversYYYYMMDD.gz.tar` 上传至 115 网盘根目录的 `/Backup`。目录缺失时会自动创建。上传后核对远端文件名、大小与 SHA-1，成功后保留本机校验凭据。手工验证支持 `--once --label cloud-cutover --verify-download`，使用独立文件名。

归档包含 CloudDrive 逻辑数据库、OpenList SQLite 快照、部署配置、私有凭据、证书和构建所需的应用文件。请在受限位置保存归档。PostgreSQL、OpenList 和 Traefik 的基础镜像由 Compose 从镜像仓库获取。

在新的 Linux amd64 Docker 主机，以 root 解压到 `/opt`，保留文件所有者和权限，然后在 `/opt/my-servers` 执行 `docker compose up -d`。

```sh
sudo tar --numeric-owner -xzpf my-serversYYYYMMDD.gz.tar -C /opt
cd /opt/my-servers
sudo docker compose up -d
```

使用空的 PostgreSQL 数据卷启动会自动创建 CloudDrive 库并还原快照。恢复后检查 `https://cloud.netioi.com/healthz`、`https://pan.netioi.com/` 和 `docker compose logs backup`。
